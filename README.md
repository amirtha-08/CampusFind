# CampusFind — JioCoder Hackathon Project

CampusFind is a responsive lost-and-found website concept for college communities. It helps students browse lost/found reports, search by item or location, filter reports, and publish a new report.

## Features
- Responsive desktop and mobile layout
- Search by item name, category, description or location
- Lost / Found filters
- Report form with item details and date
- Browser localStorage saves reports on the same device/browser
- Starter sample reports so the board is not empty
- Privacy reminder: do not publish personal contact details or student IDs

## Built with
- HTML
- CSS
- Vanilla JavaScript
- Browser localStorage

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Important demo limitation
This first version stores reports only in the current browser using localStorage. It does not yet have a shared online database, user accounts, image uploads, or messaging. If deployed as a static website, different visitors will not see each other's reports. Explain this limitation honestly. A future version could add a backend such as Supabase or Firebase with appropriate privacy and moderation.
